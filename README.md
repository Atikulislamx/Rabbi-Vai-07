## 🎨 Customization

### Adding Your Own Images

Replace the placeholder elements with real images:

1. Add your images to `assets/images/`
2. Update the HTML to use `<img>` tags instead of placeholders
3. Recommended image sizes:
   - Hero image: 800x800px
   - Gallery images: 600x600px
   - Press images: 800x450px

### Embedding Social Media Videos

#### Facebook Video
Replace the placeholder in the Videos section with Facebook embed code:
```html
<iframe src="https://www.facebook.com/plugins/video.php?href=YOUR_VIDEO_URL" 
        width="100%" height="100%" style="border:none;overflow:hidden" 
        scrolling="no" frameborder="0" allowfullscreen="true">
</iframe>
```

#### TikTok Video
Replace the TikTok placeholders with TikTok embed code from the share menu.

### Updating Social Links

Update the social media URLs in the HTML file to point to the correct profiles.

### Theme Colors

Modify the CSS variables in `style.css` under `:root` to change the color scheme:
```css
:root {
    --primary-color: #6366f1;
    --primary-dark: #4f46e5;
    --secondary-color: #f43f5e;
}
```
